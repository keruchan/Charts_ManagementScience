01 / Foundations

What are charts, graphs, and dashboards?

In Management Science, data visualization turns numbers into evidence that supports planning, resource allocation, forecasting, monitoring, and decision-making.

▥

Chart

A visual representation of data, using bars, lines, slices, dots, or other marks to communicate a comparison, distribution, relationship, or pattern.

⌁

Graph

Often used interchangeably with chart; more specifically, a display of values or relationships on axes, such as a line graph or scatter plot.

▦

Dashboard

A coordinated, at-a-glance view of important metrics and visualizations. It may be interactive, with filters that update multiple components together.

From description to decision

A chart describes what happened. A comparison establishes whether that result is unusual or meaningful. A decision also needs constraints: capacity, budget, service standards, risk, and the cost of acting. High revenue can coexist with losses; a busy branch can have more complaints but a lower complaint rate.

Variation, uncertainty, and missing data

A short rise is not a reliable forecast. Seasonality, unusual events, sample size, and changes in measurement can alter a pattern. Zero means an observed absence; missing means unknown. A percentage without its base count can hide a small sample, and correlation alone cannot establish cause.

Why visualize data instead of showing only tables?

01 · See patterns

Identify trends, seasonality, growth, decline, outliers, and unusual changes quickly.

02 · Compare clearly

Spot the highest-selling item, lowest-performing branch, or category needing attention.

03 · Decide faster

Prioritize actions using evidence—not just instinct—and communicate findings to stakeholders.

04 · Monitor targets

Track performance against quotas, service-level goals, budgets, or forecasts.

05 · Find relationships

Investigate how two variables move together and identify questions for further analysis.

06 · Tell a story

Combine evidence, context, and a recommended action into one understandable message.

Core idea: There is no universally “best” chart. The best chart depends on the question, the data type, and the decision being made. A good chart reduces confusion; a misleading one can create bad decisions.

03 / Choosing wisely

Start with the question, not the chart style

Your business question Recommended chart Reason
Are sales improving every month? Line / area Shows a trend over ordered time.
Which product sold the most? Column / horizontal bar Compares distinct categories.
What fraction belongs to each department? Pie / doughnut Shows parts of one whole when categories are few.
Do marketing expenses relate to sales? Scatter plot Displays a relationship between two numerical variables.
Where do applicants drop off? Funnel Shows stage-by-stage retention in a process.
Which team has the strongest skill profile? Radar Compares several indicators on a common scale.
What day and hour is busiest? Heatmap Finds intensity patterns in a grid.
How are exam scores distributed? Histogram Groups numerical values into intervals.
How does monthly revenue volume change? Area Emphasizes magnitude beneath a time series. Cumulative revenue requires calculating running totals first.
How much did actual results miss the target? Bullet / KPI with target Emphasizes progress toward one objective.
Common traps: Avoid 3D pie charts; compare categories on a consistent baseline; do not truncate the bar-chart axis to exaggerate differences; label units; sort bars where useful; and remember that correlation does not establish causation.

What is a KPI card?

KPI means Key Performance Indicator: a metric chosen to evaluate success against a goal. A count card highlights a single important number (such as total orders, active students, or absent employees), typically alongside a date range, comparison, or target.

Not every count is a useful KPI. Choose metrics that matter to the objective.

What is a filter or slicer?

A filter limits data to a subset, such as one branch, product, month, or status. A slicer is a clickable filtering control in Excel (and other analytics tools). A well-designed dashboard keeps connected cards and charts synchronized when a filter changes.

Important: Always indicate which filters and date ranges are active.

05 / From spreadsheet to dashboard

Building effective dashboards in Excel or Google Sheets

Practical workflow

1

Define a business question

Example: “Which branch needs attention this quarter?” Choose 3–6 metrics that answer it.

2

Prepare a clean source table

Use columns such as Date, Branch, Product, Channel, Orders, Revenue, and Cost. One row should represent one consistent observation or transaction. Avoid merged cells and inconsistent labels.

3

Create calculations

Examples: Total Revenue = SUM(Revenue); Average Order Value = Total Revenue / Orders; Gross Margin = (Revenue − Cost) / Revenue. Handle zero denominators.

4

Summarize with pivot tables

Aggregate by month, branch, or product. Use SUM, COUNT, and AVERAGE appropriately; avoid averaging percentages when a weighted calculation is needed.

5

Select the appropriate charts

Time → line; categories → bars; contribution → pie; relationship → scatter; process stages → funnel.

6

Assemble and test

Place KPI cards first, then high-priority charts. Add slicers or filter cells. Test all combinations and verify totals against the source data.

Excel and Google Sheets: practical starting points

Microsoft Excel

  1. Convert data to a Table: select range → Ctrl+T.
  2. Select the table → Insert → PivotTable.
  3. Drag Date/Branch/Product into Rows; Revenue into Values.
  4. Choose Insert → PivotChart or insert a standard chart from the summary.
  5. With a PivotTable selected, use PivotTable Analyze → Insert Slicer and/or Insert Timeline (supported versions).
  6. Use Report Connections for compatible PivotTables to control multiple summaries with one slicer.

Google Sheets

  1. Use one structured source sheet and a separate Dashboard tab.
  2. Choose Insert → Pivot table, then summarize by relevant dimensions.
  3. Choose Insert → Chart; use the Chart editor to select chart type and range.
  4. Add a Data → Add a slicer on compatible data or pivot tables. Alternatively use dropdown cells with QUERY, FILTER, or SUMIFS for a custom dashboard.
  5. Check what each slicer actually controls—charts based on unrelated ranges may not respond automatically.

Menu labels can vary by version and platform. A single filter affects multiple outputs only when their sources or formulas are explicitly connected.

Helpful spreadsheet formulas

Purpose Illustrative formula
Total revenue =SUM(F2:F1001)
Number of orders =COUNTA(A2:A1001)
Revenue for “North” =SUMIF(B2:B1001,"North",F2:F1001)
Revenue by branch + product =SUMIFS(F2:F1001,B2:B1001,"North",C2:C1001,"Coffee")
AOV (one row = one order) =IFERROR(SUM(F2:F1001)/COUNTA(A2:A1001),0)
Margin % (Cost is G) =IFERROR((SUM(F2:F1001)-SUM(G2:G1001))/SUM(F2:F1001),0)

Assumes A=Order ID, B=Branch, C=Product, F=Revenue, G=Cost; adjust to your sheet. If each row represents multiple orders, sum the order counts instead of counting rows.

🎭 Bonus twist: The misleading dashboard

A manager shows January revenue of ₱98,000 and February revenue of ₱100,000 using bars whose vertical axis starts at ₱97,000. February appears dramatically taller. Is that a fair comparison?

Not fair if the chart implies a huge growth jump. Revenue increased by only about 2.04%, but a cropped bar axis exaggerates the visual difference. Standard bar/column charts should normally start at zero. A line chart can use a tighter scale if the axis is clearly labeled and the goal is to inspect small changes.
